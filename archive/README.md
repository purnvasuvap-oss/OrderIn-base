# Archived theme apps

These folders are the old per-restaurant copies (Black, Olive, Green, Maroon, Red, Stadium, Dessert). Each one was a full customer app and a full staff app with a restaurant id written in the code.

They are kept so the history is still in git. Do not deploy them. Do not copy a bugfix into all of them.

New work goes in:

- `platform/apps/customer` — the diner app. Colours, font and logo come from the restaurant profile.
- `platform/apps/staff` — captain, kitchen, cashier, manager and owner.
- `orderin_admin` — the OrderIn company console.
- `Orderin-Only-POS/pos-system` — the offline counter.
- `platform/functions` — the Cloud Functions to deploy.

Language switching (English / Telugu / Hindi) is not in this build. It is parked.
